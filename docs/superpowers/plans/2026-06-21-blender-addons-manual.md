> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a second Blender field manual — a hard-surface **addon** cheatsheet at `/manuals/blender-addons` with a matching print PDF — sourced from `E:\Tri-Dimensional\Blender Addons\CHEATSHEET.md`.

**Architecture:** Follows the existing "web and print share DATA, not CSS" pattern. One hand-authored JSON (`src/data/blender-addons.json`) is the single source of truth, consumed by two independent renderers: a React component (`BlenderAddonsManual.tsx`, web) and `scripts/render_pdf.py` via WeasyPrint (print). One card per addon, full-width category bands, A4 portrait, 2-column grid, ~2 PDF pages. All changes to shared code are additive — the existing `blender` (Modelling) sheet is untouched.

**Tech Stack:** Next.js 16 (App Router, RSC, React 19, reactCompiler), MDX, Zod, Tailwind v4; Python + WeasyPrint + markdown-it-py for the PDF; OpenNext/Cloudflare for deploy.

## Global Constraints

- **No new manual `type`** — reuse `type: component`; a new optional `printLayout` frontmatter field steers the PDF renderer. Do not edit the `component`/`prose`/`poster` renderers' behavior.
- **Do NOT touch** `src/components/BlenderManual.tsx`, `src/data/blender-sections.json`, `scripts/print/component.css`, or the existing `render_component_body` — the Modelling sheet must keep working.
- **Single source of truth:** all addon content lives in `src/data/blender-addons.json`. The web component and `render_pdf.py` both read it. Never duplicate content into the component or CSS.
- **Inline-HTML fields are raw HTML** (`<kbd>`, `<b>`): `keys`, `desc`, `what`, `when`, `notes`. They are NOT HTML-escaped by either renderer (script-controlled content; mirrors `BlenderManual`). Plain-text fields (`name`, `category`, `title`, `sub`, `num`) ARE escaped in the Python renderer.
- **Commit hygiene (Gavin's rules):** `git add` only the specific files this plan creates/modifies — never `git add -A`/`.`. Commit messages must not contain the words "claude" or "anthropic"; do NOT add a `Co-Authored-By` trailer. The repo's git root is `G:\code\nerdz\nerdz-landing`.
- **Verify gate:** a pre-commit hook blocks commits without a verification stamp. Run `npm run build` (which also runs `gen` and validates the data) before each commit to create the stamp. Every file edit clears the stamp, so build immediately before committing.
- **Palette:** reuse existing tokens — web component uses the scoped `.manual` paper tokens (`--ink`, `--ink-mid`, `--ink-mute`, `--purple`, `--gold`, `--paper-card`, `--paper-deep`, `--paper-soft`, `--rule`, `--rule-strong`); print CSS uses `base.css` tokens of the same names. Do not introduce new colors.
- **PDF render environment:** `scripts/render_pdf.py` needs WeasyPrint + markdown-it-py + PyYAML from the venv at `/home/gavin/home-ops/.venv` (a WSL path). Run the PDF step under WSL (or any env with those deps), not necessarily the Windows shell.

```python
def render_addon_body(slug: str) -> str:
    """Addon-cheatsheet layout: a flat ordered list of band / menu / card /
    footer items from <slug>.json. One card per addon, full-width category
    bands, 2-col grid (component-addons.css). Inline-HTML fields (desc, keys,
    what, when, notes) are passed through raw; plain-text fields are escaped."""
    data_path = DATA_DIR / f"{slug}.json"
    if not data_path.exists():
        raise FileNotFoundError(
            f"addon sheet '{slug}' needs {data_path} (hand-authored data file)"
        )
    items = json.loads(data_path.read_text(encoding="utf-8"))

    out = []
    for it in items:
        kind = it.get("kind")
        if kind == "band":
            out.append(
                '<div class="ad-band">'
                f'<span>{html_lib.escape(it["category"])}</span>'
                f'<span class="ad-band-num">{html_lib.escape(it.get("num", ""))}</span>'
                "</div>"
            )
        elif kind == "menu":
            out.append(
                '<section class="ad-card ad-menu">'
                f'<h2 class="ad-name">{html_lib.escape(it["title"])}</h2>'
                f'{_rows_html(it.get("rows", []))}'
                "</section>"
            )
        elif kind == "footer":
            out.append(f'<div class="ad-foot">{html_lib.escape(it["text"])}</div>')
        else:  # card
            badge = '<span class="ad-badge">menu-only</span>' if it.get("menuOnly") else ""
            sub = f'<div class="ad-sub">{html_lib.escape(it["sub"])}</div>' if it.get("sub") else ""
            what = f'<p class="ad-what">{it["what"]}</p>' if it.get("what") else ""
            when = (
                f'<p class="ad-when"><span>When</span> {it["when"]}</p>'
                if it.get("when") else ""
            )
            notes = "".join(f'<div class="note">{n}</div>' for n in it.get("notes", []))
            out.append(
                '<section class="ad-card">'
                f'<h2 class="ad-name"><span>{html_lib.escape(it["name"])}</span>{badge}</h2>'
                f'{sub}{what}{when}{_rows_html(it.get("shortcuts", []))}{notes}'
                "</section>"
            )
    return f'<div class="sheet-body ad-grid">{"".join(out)}</div>'
```
